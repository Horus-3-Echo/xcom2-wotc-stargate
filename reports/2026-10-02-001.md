# Plánovaný běh 8 — oprava UI dispatch a migrace mise

Datum: 2026-10-02, Europe/Prague.  
Vstupní `main`: `082d8fd301c326877763a4a874a95b977020d5ad`.  
Úkol: WSG-004B, opravit doložený T05 FAIL verze 0.2.1 bez změny cizích
mission-source callbacků.

## Změna

- Přidána `XComGameState_MissionSite_Stargate`. Její `MissionSelected`
  loguje vlastní ID a volá zděděné `SelectSquad()` přímo, takže se vyhne
  uzavřenému dispatchi `XComHQPresentationLayer.OnMissionSelected`.
- Factory od verze 0.2.2 vytváří tuto podtřídu. Pokud najde aktivní starou
  základní MissionSite z 0.2.1, v jednom change state ji odstraní, vytvoří
  nový `Reward_None` a novou podtřídu, aktualizuje uloženou referenci a zapíše
  `prototype-mission-migrated old=<n> new=<n> region=<n> type=<typ>`.
- Nové i migrované nabídky vybírají nejdříve region s `HaveMadeContact()`;
  obecný `SelectRandomMissionLocation` zůstává pouze fallbackem kampaně bez
  kontaktovaného regionu. Tím se odděluje UI chyba od čitelnosti umístění.
- Loader marker je 0.2.2, projekt zahrnuje novou třídu a T05 v BUILD.md nyní
  rozlišuje migraci starého save od čistého vytvoření.
